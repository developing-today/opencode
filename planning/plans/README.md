# Plans

Implementation plans break a roadmap item into steps. Each step is small enough for one PR and says how to tell it is done. Use the [plan template](../templates/plan.md).

Name a plan `<short-name>.md`, or `<UTC datetime>_<short-name>.md` when the order matters. Link each plan from the roadmap row it implements, and keep its Progress section current as PRs merge.
